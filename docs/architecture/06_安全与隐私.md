# 安全与隐私详细设计

系统处理销售人员所记录的客户资料，风险包括越权读取、误关联、原始语音外泄、模型重识别、备份复活和供应商二次使用。方案先限定处理目的、必要性和合法依据，再通过最小化、加密、权限及可核查的删除降低风险。

## 数据分类与角色

| 数据 | 内部保护级别与处理 |
| --- | --- |
| 账号、客户姓名、联系方式、关系及可识别事实 | 个人信息；访问需租户权限，敏感字段加密、最小展示 |
| 证件、金融账户、健康资料、未满十四周岁者信息 | 按最高保护级别；前两者是否法定敏感视具体情形，健康、金融账户和未满十四周岁者信息依法属于敏感个人信息 |
| 口述音频、完整转写 | 可能包含直接标识和其他人的信息；加密、限制转写服务及保存时间 |
| 脱敏文本、向量、摘要和建议 | 仍可能被关联识别，采用访问控制、磁盘加密、生命周期和删除 |
| 事件、指标与审计元数据 | 最小化保留，不允许包含原文、完整姓名、电话、证件、密钥、签名 URL |

产品方、保险机构、销售人员和供应商的个人信息处理者或受托处理角色，需按实际业务与合同界定。销售人员同意使用软件不等于客户同意处理其信息。涉及健康等敏感个人信息及未成年人时，应完成适用的必要性、告知、单独同意或监护人同意等要求，并支持验证、撤回与权利请求。[中华人民共和国个人信息保护法](https://www.miit.gov.cn/jgsj/zfs/fl/art/2022/art_515a4b20c12f430eab54bb4f56d89f56.html)。

## 音频处理的两条路径

1. **优先评估本地或受控云 ASR**：设备端必须能证明离线运行，不能假定系统语音 API 不联网；受控云 ASR 的模型、主机、日志、访问与数据保留均由产品方控制。记录口述备忘也需要相应的个人信息处理依据。
2. **备选托管 ASR**：服务商必须接收原始音频才能转写。上线前核对地区、子处理方、告知和合法性、数据使用与模型训练、留存删除、转委托、入侵响应、传输和合同审计。若无法满足，则不可用该路径；切换国内其他服务商也需同样评估。

备选 paraformer-realtime-v2 通过加密 WebSocket 接收原始音频，须验证出站网络、请求超时及供应商日志策略；不得把音频放入一般业务日志与队列。qwen3-asr-flash 是基于大语言模型的语音模型，不能用未脱敏原音频调用，以符合 LLM 调用前脱敏的要求。

## 音频与字段加密

- 设备本地草稿使用随机数据密钥加密，并由 iOS Keychain 或 Android Keystore 保护；上传时经 TLS 传输。云端对象至少启用云侧 KMS 加密；对于更高保护级别，应用侧按对象使用 AES-256-GCM 加密后上传，服务器授权解封才能转写。
- 应用侧加密的一个可实施方案：服务端为记录创建随机对象 DEK，经 TLS 送给已认证设备并以 KMS 密钥包装后持久化；设备只在受保护内存中使用 DEK。离线草稿使用本地密钥，联网后在设备上受控重加密再上传。密钥分发、轮换和丢失设备路径在上线前审查。
- 分片对象使用唯一 DEK、每片唯一 nonce、独立认证标签与经认证清单；AAD 绑定 tenant_id、record_id、分片序号及加密版本。不能重复使用同一密钥与 nonce，不能仅靠普通哈希替代认证加密。
- 联系方式和证件按字段 AES-256-GCM 加密；客户或记录级 DEK 经 KMS 主密钥包装，附密钥版本、nonce、AAD 和认证标签。KMS 主密钥按环境隔离并限制服务身份；轮换包括 DEK 重新包装和受控灰度。
- 精确检索只保存按租户独立密钥计算的 HMAC，规范化过程记录版本；该令牌泄露租户内相等性，不用于跨租户匹配。为 HMAC 与数据加密使用分离密钥，轮换时双令牌查询并回填。

不要为 15 万个用户逐个创建 KMS 主密钥。以有限数量的环境/服务主密钥管理大量包装数据密钥，但需测算 GenerateDataKey、Decrypt 的吞吐和调用成本。目标情景每月约 510 万条录音，仅每录音一次生成加一次解封即至少约 1020 万次密钥操作，重试、字段读取和重包装另计；实际可通过经安全评估的短期密钥缓存减少调用，不能将缓存置于普通日志或共享缓存。

## 大模型脱敏与映射

1. 输入在受控环境经过规则、中文数字规范化、上下文识别及中文实体模型；覆盖电话、证件、姓名、口语断句和常见 ASR 错误。针对高风险字段规则按实际数据维护。
2. 姓名、联系方式、证件和其他必要标识替换为仅本次任务有效的占位符。为避免跨任务关联，不使用全局稳定的客户标识；模型收到的是脱敏内容和无敏感信息的来源编号。
3. 临时映射仅存在有访问控制的受控内存或加密短期存储；禁止进入队列、提示词、日志及向量库。任务崩溃后优先从仍授权的加密原文重新执行脱敏，不长期保存映射。
4. 超出可识别范围、组件故障、缺乏适用依据或策略未通过时，拒绝外部 LLM 与 embedding 请求并进入待处理；检测链路不可用不能降级为发送原文。
5. 输出通过模式、证据和敏感信息检查；服务端按当前用户权限展示原始来源。只要仍可被关联识别，脱敏结果就不能按匿名数据处理。

模型网关与 LLM、embedding 服务之间使用经身份验证的 HTTPS/TLS；模型请求体不包含占位符映射或直接标识。传输加密不能取代脱敏，脱敏文本也不能取代传输加密。

持续用经授权或合成样本评估各类直接标识符的端到端召回与误报；试点目标为按类型单侧 95% 置信下限至少 99.9%。有限测试无法保证零泄漏，不能把未命中识别规则等同于“绝无敏感信息”。

## 访问控制和监控

- 业务用户仅能访问自己的租户；API、数据库复合外键及 RLS、对象、缓存和向量库独立校验。数据库角色不得拥有 BYPASSRLS；连接池使用事务局部租户上下文并测试泄漏。
- 员工管理端默认看不到客户原文。需要排错时使用工单、最小授权、限时审批、操作审计和去标识样本；严禁共用管理员账号和将生产数据复制到测试环境。
- 密钥服务、模型网关、ASR 适配器、调度器使用不同身份和最小 IAM；出站网络只允许经批准的国内区域服务。配置禁止模型联网、工具执行和未授权训练。
- 监控异常导出、批量解密、跨租户访问、KMS 调用突增、DLP 失败、异常设备登录、密钥轮换失败和备份恢复。日志不保存敏感字段或原始模型请求。

## 删除与数据权利

删除请求支持按客户、记录或账号处理，并对请求人进行适当身份核验。权威库先写删除墓碑、撤销访问与授权、增加版本，取消等待任务和额度预留；所有读取立即排除相关数据。随后删除或失效事实、关系、摘要、向量、倒排、缓存、对象、临时映射、报表衍生物和服务商副本，记录每个子任务和回执。

在线清理目标 72 小时，备份最长 30 天滚动到期；法律要求保留的少量数据隔离并限制用途。跨区恢复时先验证并重放删除墓碑，未能确认完整性不得对外服务。对象 DEK 或其备份副本仍存在时，不能把删除在线密钥描述为即时完成所有备份删除。

## 安全验收

发布前验证：跨租户 API、SQL、对象链接、向量、缓存和任务的越权；弱网下对象重传；DLP 中文口语数字与错字；权限撤回与旧任务写回；日志脱敏；导出授权；KMS 密钥轮换和失效；备份恢复后删除不复活；ASR 与 LLM 供应商合同和实际数据路径一致。

## 账号恢复与导出边界

访问令牌短时有效，刷新令牌旋转并检测重复使用；设备会话可撤销，换号、恢复购买与敏感操作要求重新认证。短信验证加入设备/账号/IP 速率限制与滥用防护；账号恢复不能只凭当前手机号码把历史客户数据自动迁给新持有人。客服介入恢复须走独立身份核验和审计。

导出按创建与实际下载两次校验权限和版本，后台生成加密压缩文件，短期下载凭证不可写日志；默认不导出证件及详细健康信息，用户另选且具备权限时再包含。导出申请时检查客户处理依据与暂停联系策略，数据可携权利导出和营销名单导出采用不同目的限制。记录导出动作和撤销/到期，不承诺能删除用户已经下载的文件。

“转写后删除录音”表示云端短暂处理后清除音频，不表示音频未上传；要做到不上传必须使用经验证的离线 ASR。客户端设置同时显示处理路径和保存期限。同步、客服、通知、支付、崩溃上报 SDK 按最小化原则纳入供应商清单，不为诊断默认收集屏幕和原文。

暂停经营、撤回授权与删除分别有状态。删除接受后进入不可用状态和清理流程，原型不提供会恢复已撤权数据的“撤销删除”；只允许在最终提交前取消。不可安全删除的法定留存数据单独列明目的及受限期限。
