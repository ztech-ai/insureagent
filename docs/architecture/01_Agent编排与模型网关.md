# 云端 Agent 编排与模型网关设计

Agent 的任务是把用户记录转成有来源的客户信息，并基于授权材料给出可审核的经营建议。采用确定性工作流控制状态和权限；模型仅生成受约束的候选内容，不直接写数据库、跨租户查询或联系客户。

## 模块与责任

| 模块 | 输入 | 输出与责任 |
| --- | --- | --- |
| Intake API | 已认证的文本或音频元数据 | 校验格式、幂等、额度及持久化状态 |
| ASR Adapter | 已授权的音频片段 | 转写结果、时间戳、供应商请求 ID；不得把录音写日志 |
| DLP Gateway | 原始转写或用户提问 | 最小化文本和任务内映射；拒绝不满足策略的外部调用 |
| Extraction Flow | 脱敏文本及受限字段模式 | 人物、事实、时间和建议任务候选及原文证据 |
| Identity Resolver | 租户内候选及安全令牌 | 已确认关联或待确认候选；不把模型置信度当作身份证据 |
| Insight Flow | 已确认事实、最小必要片段、产品资料状态 | 可解释建议、待核实项、来源及有效期 |
| Question Flow | 用户问题、当前租户与权限 | 检索后生成带引用回答，证据不足时拒答 |
| Model Gateway | 经政策批准的请求 | 负责模型选择、速率与成本控制、超时、重试和元数据审计 |

以上可以放在一个代码仓库，API、普通工作进程和调度进程以不同启动命令部署。模型请求与客户资料的权威更新由不同边界负责。

## 语音或文字记录工作流

1. API 以租户加 client_record_id 幂等落库。音频上传完成后验证内容大小、类型、哈希及对象拥有者；对象和数据库达持久化条件才向客户端确认。
2. Outbox 通知工作进程；获取记录的 tenant_id、record_id、expected_version 和授权状态。对音频进行格式检查与转写；文字直接进入下一阶段。
3. 受控 DLP 识别姓名、电话、证件等，生成任务内占位符；检测失败或覆盖能力不足时进入可见错误，阻断外部模型请求。
4. 模型按 JSON Schema 返回事实候选及证据，服务端检查类型、长度、枚举、人物占位符及引用片段。模型不得返回或选定数据库客户 ID。
5. 身份解析服务在当前租户判断候选；不确定时将归属标记为 ambiguous，未确认事实不能进入已确认客户资料。
6. 确认后的事实和来源在一个事务中写入，递增版本并写出事件；建议、索引和任务异步更新。若用户删除、撤权或编辑使 expected_version 过期，丢弃旧结果并视情况重跑。

处理状态、失败阶段和可重试原因对用户可见；外部 ASR/LLM 长时间不可用时保留已保存记录，不伪造“处理完成”。无网络的本地草稿由移动端保证加密保存。

## 音频适配与分段

首选在设备端或受控云内完成 ASR。经安全、合同和授权核验后的托管备选为 paraformer-realtime-v2：工作进程从授权对象解密音频，通过 TLS WebSocket 以服务支持的格式发送语音流并接收转写。针对文件长度、采样率、超时、断线续传、重复计费、并发上限及长录音分段进行集成验证；无法正确拼接的姓名、数字与句子标记待用户校正。

托管 ASR 服务商会接触原始声音，它不等同端侧处理。若改用 paraformer-v2 录音文件接口，官方文档要求公网可访问文件 URL，必须先证明短期签名 URL、权限、到期、脱敏日志和供应商读取策略可控，并评估新增攻击面。qwen3-asr-flash 本身基于大语言模型，不能用未脱敏原音频调用；不能因为它用于转写就绕过用户对 LLM 脱敏的要求。[实时 Paraformer](https://help.aliyun.com/zh/model-studio/paraformer-realtime-v2)；[录音接口约束](https://help.aliyun.com/zh/model-studio/non-realtime-speech-recognition-user-guide)；[Qwen ASR 模型说明](https://help.aliyun.com/zh/model-studio/qwen3-asr-flash)。

## 经营建议工作流

触发来源包括用户主动请求、记录确认后的防抖事件和定期筛选。调度器先按权益、近期互动、到期任务、最近分析时间和剩余额度筛选，不全量扫描所有客户并直接调用模型。

每次运行固化：租户、客户、事实及来源版本、目标类型、模型及提示词版本、最大 token、预算、生成时间与过期时间。先获取最小化、已授权的事实及至多经评测确定数量的片段；没有依据即输出“资料不足”。结果经过证据校验和销售合规规则检查后生成 suggestion 草稿；用户确认后才创建或修改正式任务，用户联系客户仍是手动行为。

事实撤回、客户改正或资料过期时，已有建议立即失效；重新分析应去重并受频率及成本控制。免费层不执行定期深度分析；专业版权益示例见成本设计，实际以权益服务配置为准。

## 客户问答工作流

入口先判断意图和权限：客户资料查询、跨客户列表筛选、记录摘要、经营建议。结构化问题先查结构化字段，开放式问题走第 04 文档的租户内混合检索。服务端验证所有引用确实属于当前租户、未删除且仍有效；模型只取得最小必要证据，不允许通过内容中的指令扩权。

回答按“已确认事实、待确认信息、建议”分区；找不到证据时说明资料不足。用户询问证件或电话时，由独立权限和敏感字段展示流程处理，不把号码发送给生成模型。

## 模型调用契约

请求由网关构造，包括 task_type、tenant_budget_key、模型快照、提示词版本、脱敏文本或片段 ID、输出 JSON Schema、token 上限、截止时间和 trace_id。仅在网关内部使用模型 API 凭证。

```json
{
  "task_type": "extract_interaction",
  "schema_version": 1,
  "input": "[客户甲]近期想了解家庭保障，下周再联系。",
  "source_ref": "record:opaque-id:revision-3",
  "max_output_tokens": 600
}
```

输出示例包含人物占位符、候选事实、证据短句与原文相对位置、原始时间表达式；服务端再校验证据存在性、人物归属和版本。引用无法对应输入时拒绝该候选，不回填猜测。提取结果只表示候选；相对日期以记录发生时间和用户时区计算，无法确定时由用户选择。

## 模型路由与限流

- 固定版本路由：抽取和问答使用 qwen-flash-2025-07-28，深度建议使用 qwen-plus-2025-04-28 非思考模式，语义向量使用 text-embedding-v4 的 768 维。模型性能通过人工标注的真实授权或合成语料验证后才能启用。
- paraformer-realtime-v2 在北京地域官方文档列示 1200 RPM，限流说明列示 20 次/秒建连；目标情景平均约 118 个录音请求每分钟、峰值约 595，峰值约 9.92 次/秒。长音频重连与重试会增加建连；需另与供应商确认同时进行中的会话数上限并实测吞吐。不能仅凭 RPM 推断 893 路实时等效工作量可以被承载。[ASR 模型限流](https://help.aliyun.com/zh/model-studio/rate-limit)。
- 建议模型的 RPM/TPM、输入/输出 token、实时/批处理支持须按固定模型快照逐项核验。目标情景 500 万次建议/月若集中在每日 8 小时，平均约 347 次/分钟；示例 qwen-plus-2025-04-28 文档显示 60 RPM，需申请扩容或减少频率。不得把模型单价当成吞吐承诺。[模型信息](https://help.aliyun.com/zh/model-studio/qwen-plus)。
- 网关采用全局及租户令牌桶、优先级和熔断：记录转写与人工提问高于后台建议。超限可排队、返回预计状态或拒绝；不得在无授权时切换到其他地域或外部厂商。

## 超时重试和可观测性

模型超时有可能已在供应商侧计费或完成。若供应商支持查询请求状态或幂等键，优先查询并复用；不支持时按最多两次重试和预算上限处理，记录不确定成本，不能声称外部调用恰好一次。有限重试采用指数退避和随机抖动，明确将 4xx 策略错误与 429、5xx 区分；超过上限进入可见失败和死信处理。

采集任务类型、模型版本、延迟、输入输出 token、供应商请求 ID、状态与脱敏命中类别，不采集客户原文、身份证、电话、录音或临时映射。生产回放只使用经过授权的脱敏数据；禁用默认会记录完整提示词的第三方追踪服务。

## 评测与发布

模型改版采用固定回归集、影子运行及灰度：评估字段与人物归属、证据正确性、漏检、无依据回答、延迟和成本；使用模型评分不能替代人工标注。针对同名、口语数字、中文转写错误、提示注入、无依据保险承诺和删除后重放设阻断用例。出现高危错误立即切回经审核的版本。

## 处理中断与可用结果

ASR 已成功且转写可读取时，即使抽取失败，保存状态仍为 stored、处理为 partial_success，用户可以读、改文字或仅重试抽取。未取得客户归属不算模型失败，不应反复调用 ASR；额度不足时为 blocked_quota，用户可以保留草稿或已有转写，额度恢复后由用户请求或按事先约定续处理。后续阶段不得删除前阶段可用成果。

客户端能确认客户关联，并逐项勾选确认事实和任务；默认不勾选推断或不确定字段。自动关联记录仅影响 linked，不能把 proposed 事实升级成 confirmed。建议使用资料中尚未确认的内容时明确标注待核实，具体投保或产品适配结论不能基于它生成。

联系偏好和客户处理依据在筛选、生成、建议展示及任务创建四处校验。勿扰或撤权后在运行任务不再产生新的营销建议。没有有效且适用的产品知识资料时，只输出需了解的问题；资料包括批准人、版本、地域、渠道、有效时间和撤回状态，过期资料立即退出检索。

对模型等待中的取消、超时和断开，保存 provider_request_id 与调用状态；不支持幂等或查询的供应商只能限制重复成本，不能保证不重计。全链路 trace 仅传不含个人信息的标识。
